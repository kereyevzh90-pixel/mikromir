# Микромир

Игра-симулятор бактерий. **Игра в разработке и выглядит сыро** — это черновик, а не готовый продукт.

## Как запустить

**Как программу (рекомендуется — быстрее и работает онлайн):**
- двойной клик по `Запустить игру.bat`
- или в консоли: `npm install` (один раз), затем `npm start`

**Как страницу:** открыть `index.html` в браузере. Всё работает, кроме онлайна.

## Режимы

- **Лаборатория** — песочница: 28 сред, 37 видов, еда, антибиотики, иммунитет, конструктор своей клетки.
- **Выживание** — ты одна клетка в чужой воде; мутации за съеденные азот и фосфор.
- **Онлайн-выживание** — через интернет (сервера-комнаты, игроки со всего мира; работает и в браузере) или по локальной сети по адресу (только в программе).
- **Заражение / Наблюдение / Погружение** — жизнь штамма внутри человека: рана → кровь → лёгкие → кишечник → сепсис.
- **Пандемия** — карта мира: страны, перелёты, симптомы, лекарство.

## Онлайн через интернет (сервера)

В игре: «Онлайн-выживание» → имя, клетка (из «Мои клетки») → в разделе «Интернет» список комнат («Сервер 1 · Пруд», «Сервер 2 · Рана», по 8 мест) → **Войти**. Мир считает сервер; после смерти клетка возрождается через 5 с. Адрес сервера вписан в поле «адрес сервера» (запоминается).

### Как поднять свой сервер (`server.js`, без зависимостей)

```
node server.js                 # http://localhost:8080 — комнаты, профили, раздаёт игру как сайт
```
Переменные: `PORT` (порт), `BASE_URL` (внешний адрес, например `https://mikromir.onrender.com`),
`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` — для входа через Google.

Чтобы играли «со всего мира», сервер нужно разместить в интернете. Самый простой бесплатный путь — **Render.com**
(Vercel не подходит: там нет постоянно работающих процессов и WebSocket):

1. Выложить папку игры на GitHub (без `node_modules`, `dist`, `data` — они в `.gitignore`).
2. На render.com: **New → Blueprint** → выбрать репозиторий → Apply. Файл `render.yaml` уже всё описывает.
3. Через пару минут появится адрес вида `https://mikromir.onrender.com` — это и сервер, и сайт с игрой.
4. Вписать этот адрес в `NET_SERVER_DEFAULT` в `index.html` и пересобрать exe (`npm run build`).

Бесплатный сервер засыпает через 15 минут без игроков и просыпается ~за минуту при первом входе.
Полученный адрес (`https://…`) вписать в игре в поле «адрес сервера» или в `NET_SERVER_DEFAULT` в `index.html`,
чтобы он был по умолчанию у всех, кто скачал игру. По этому же адресу игра открывается прямо в браузере.

Комнаты настраиваются в `server.js` (`ROOMS`: имя, среда, число мест). Данные профилей — в `data/`.

### Вход через Google

1. В [console.cloud.google.com](https://console.cloud.google.com) → «APIs & Services» → «Credentials» → создать **OAuth client ID** (Web application).
2. Authorized redirect URI: `BASE_URL/auth/google/cb` (например `https://mikromir.onrender.com/auth/google/cb`).
3. Запустить сервер с `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
4. В игре: Профиль → **G Google** → в браузере выбрать аккаунт → покажут код из 6 цифр → ввести в игре.

Профиль (почта+пароль или Google) хранит прогресс на сервере — на любом устройстве один и тот же. Без входа —
гость `Гость123`, прогресс только на этом устройстве.

## Онлайн по локальной сети (без сервера)

1. Оба запускают программу (`Запустить игру.bat`).
2. Хозяин: «Онлайн-выживание» → «Локальная сеть» → среда → **Создать игру**. На экране появится его адрес (например `192.168.1.5`).
3. Гость: вписать адрес хозяина → **Подключиться**.
4. Мир считает хозяин. Порт `43100` (для Windows-брандмауэра — разрешить при первом запуске).

## Сборка exe

`npm run build` (нужен `electron-builder`: `npm i -D electron-builder`).
